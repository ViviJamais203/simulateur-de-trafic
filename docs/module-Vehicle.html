(inner) computeArcCenter(p1, dir1, p2, dir2) → {Object}

Calcule le centre de l'arc de cercle permettant de relier deux points avec leurs directions tangentes respectives. Résout l'intersection des deux normales aux directions (perpendiculaires) : le centre de l'arc est le point équidistant des deux extrémités sur ces normales.
Parameters:
Name Type Description
p1 Object Point de départ de l'arc.
dir1 Object Direction tangente au départ (vecteur unitaire).
p2 Object Point d'arrivée de l'arc.
dir2 Object Direction tangente à l'arrivée (vecteur unitaire).

(inner) computeLaneEntryPoint(road, direction) → {Object}

Calcule le point d'entrée d'une voie de circulation (avec décalage latéral) à l'extrémité d'accès d'une route. Le décalage latéral (LANE_OFFSET = 25px) permet de séparer les deux sens de circulation.
Parameters:
Name Type Description
road Road La route cible.
direction 'AtoB' | 'BtoA' Le sens dans lequel on entre sur la route.
