Class: Intersection

Intersection.Intersection(id, x, y, cycleDuration)

Représente une intersection routière avec gestion automatique des feux de circulation. Les feux sont activés un par un dans l'ordre horaire, avec une courte période de transition (tous au rouge) entre chaque changement de feu actif.

initTrafficLights()

Initialise les feux de circulation pour toutes les routes connectées. Trie les routes dans le sens horaire, crée un feu par route, et met le premier feu au vert.

update(deltaTime)

Met à jour le cycle des feux de circulation pour ce pas de temps. Alterne entre deux phases : - Phase "transition" (1 seconde) : tous les feux sont au rouge entre deux cycles. - Phase "cycle" : un seul feu est au vert pendant `cycleDuration` secondes.
Parameters:
Name Type Description
deltaTime number Temps écoulé depuis le dernier pas (en secondes).
