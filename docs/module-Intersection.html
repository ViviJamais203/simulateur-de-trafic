(inner) sortRoadsClockwise(roads, cx, cy) → {Array.<Road>}

Trie un tableau de routes dans le sens horaire par rapport à un centre donné. Pour chaque route, calcule l'angle `atan2` depuis le centre vers l'extrémité externe de la route (le point qui n'est pas le centre de l'intersection).
Parameters:
Name Type Description
