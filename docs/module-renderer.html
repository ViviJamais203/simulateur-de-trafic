Module: renderer

Module de rendu 2D du simulateur sur un canvas HTML. Dessine les routes, les intersections, les feux de circulation, les zones de congestion et les véhicules.

Methods

(static) render(ctx, network, vehiclesopt, congestionZonesopt)

Efface le canvas et redessine l'ensemble de la scène de simulation. Ordre de dessin : routes → zones de congestion → intersections (avec feux) → véhicules.
Parameters:
Name Type Attributes Default Description
ctx CanvasRenderingContext2D Contexte 2D du canvas.
network Object Le réseau routier à dessiner.
vehicles Array.<Vehicle> <optional>
 [] Liste des véhicules actifs à dessiner.
congestionZones Map.<string, Object> <optional>
 new Map() Zones de congestion indexées par clé `roadId-direction`.

(inner) drawCongestionZone(ctx, zone)

Dessine la zone de congestion d'une voie sous forme d'un segment épais orange semi-transparent (rgba(255, 120, 0, 0.4)). La zone s'étend de `minProgress` à `maxProgress` le long de la voie, en respectant le décalage latéral de voie (LANE_OFFSET = 25px).
Parameters:
Name Type Description
ctx CanvasRenderingContext2D Contexte 2D du canvas.
zone Object La zone de congestion à dessiner.

(inner) drawHexagon(ctx, intersection)

Dessine un hexagone régulier pour représenter une intersection hexagonale. L'hexagone est orienté pointe en haut grâce à un décalage angulaire de `Math.PI / 6`.
Parameters:
Name Type Description
ctx CanvasRenderingContext2D Contexte 2D du canvas.
intersection Intersection L'intersection dont `shapeRadius` définit le rayon.

(inner) drawTrafficLight(ctx, light, intersection)

Dessine le feu de circulation d'une route à l'extrémité `end` de celle-ci, décalé latéralement vers l'extérieur de la chaussée (ROAD_WIDTH / 2 + LIGHT_EDGE_MARGIN). Couleur : vert (#22c55e) si feu vert, rouge (#ef4444) sinon.
Parameters:
Name Type Description
ctx CanvasRenderingContext2D Contexte 2D du canvas.
light TrafficLight Le feu à dessiner.
intersection Intersection L'intersection contenant ce feu (sert à calculer l'orientation de la route).
